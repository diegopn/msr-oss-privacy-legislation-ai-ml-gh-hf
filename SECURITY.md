# Política de segurança

## Versões cobertas

Este repositório não publica releases numeradas. A branch `main` é a linha atualmente considerada para correções; commits anteriores não têm manutenção garantida.

## Como relatar uma vulnerabilidade

Use o [formulário privado de relato de vulnerabilidade do GitHub](https://github.com/diegopn/msr-oss-privacy-legislation-ai-ml-gh-hf/security/advisories/new), se estiver habilitado. Não publique detalhes exploráveis em issues, discussions, pull requests ou comentários.

Se o formulário privado estiver indisponível, abra uma issue apenas para pedir um canal privado. Não inclua detalhes técnicos, credenciais, dados pessoais, trechos de conteúdo coletado, logs ou código de prova de conceito nessa issue.

No relato privado, informe, quando relevante, o arquivo ou commit afetado, passos mínimos de reprodução, impacto provável e mensagens de erro. Remova `GITHUB_TOKEN`, `HF_TOKEN`, outros segredos, dados pessoais e conteúdo desnecessário de logs e exemplos.

Teste somente contas, dados e sistemas para os quais você tem autorização. Não acesse dados de outras pessoas nem interrompa serviços.

## Escopo

Esta política cobre o código R de coleta e análise, a integração com as APIs do GitHub e do Hugging Face, os artefatos gerados e os workflows e páginas mantidos neste repositório. Vulnerabilidades nas plataformas ou nas APIs de terceiros devem ser encaminhadas aos respectivos mantenedores; falhas na forma como este projeto as integra ou processa respostas permanecem no escopo.

As coletas tratam conteúdo público, que pode conter dados pessoais. Ao relatar um problema, compartilhe somente o material necessário e remova identificadores e dados que não sejam essenciais.

Os relatos são analisados conforme a disponibilidade do mantenedor. Não há prazo garantido de resposta ou correção; quando possível, a divulgação pública será coordenada após uma correção.
